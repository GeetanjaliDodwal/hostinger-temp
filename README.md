Mandar International footer UI patch

This repository contains a scoped CSS patch for improving the footer UI on
https://mandarinternational.com/.

## How to apply

1. Open WordPress Dashboard.
2. Go to Appearance > Customize > Additional CSS.
3. Paste the contents of `mandar-footer-ui.css`.
4. Publish the customizer changes.
5. Clear any WordPress/cache plugin cache and browser cache.

The CSS is scoped to `.site-footer.sbmart-footer-builder` so it only targets
the current Elementor/SBMart footer.
